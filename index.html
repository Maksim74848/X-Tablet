Интерфейс, который действительно лежит рядом с пилотом.

Один экран остаётся X‑Plane. На втором — приборы, карта, системы, чек-листы и управление. X‑Tablet создан именно под такой двухэкранный сценарий.

Возможности

Не ещё одно окно.
Отдельный инструмент.

X‑Tablet рассчитан на физический второй экран рядом с пилотом, чтобы меньше отвлекаться от основной панели X‑Plane и быстрее получать нужную информацию.

✈

Live Flight Deck

IAS, altitude, V/S, heading, pitch, bank, ground speed, track, fuel и другие параметры поступают из текущей сессии X‑Plane.

⌘

Реальные команды

Desktop‑часть использует официальный Web API X‑Plane для команд и потоковых данных, а не имитацию случайных клавиш.

📱

Телефон или планшет

Подключение по локальной сети превращает браузер телефона в дополнительный экран без обязательного отдельного мобильного приложения.

◈

Диагностика

Статус X‑Plane, API‑версия, возраст последних данных, журналы и состояние companion‑канала собраны в одном месте.

⚙

Hotkeys и layouts

Панели можно адаптировать под свой сценарий: частые команды, системы, радио и собственный порядок экранов.

Local First

Сам live‑обмен X‑Plane ↔ PC ↔ телефон идёт локально. Облако не нужно для передачи данных полёта.

FAQ

Всё, что важно знать.

Честно про оплату, загрузку и связь с X‑Plane.

Нужно ли приложение на телефон?
Нет. Телефон или планшет используют браузер. Desktop‑часть X‑Tablet соединяет его с X‑Plane.
Доступен ли X‑Tablet на Windows, Linux и macOS?
Да. Сайт показывает отдельные релизные файлы для Windows, Linux и macOS. Для macOS релиз может содержать отдельные Intel и Apple Silicon сборки.
Как понять, что покупка прошла?
Только после получения Telegram successful_payment. После этого бот создаёт или продлевает лицензию, показывает ключ и кнопку «Открыть мои файлы».
Что будет при копировании ключа на другой ПК?
Первый ПК получает привязку device ID + локального device secret. Второй компьютер тем же ключом не активируется.
Как перенести лицензию?
В Telegram‑боте есть команда переноса устройства. После сброса следующий ПК сможет активироваться.
Что именно используется в X‑Plane?
Встроенный Web API X‑Plane: REST и WebSocket. DataRef streaming и Commands поддерживаются с версий API, указанных в документации X‑Plane.
