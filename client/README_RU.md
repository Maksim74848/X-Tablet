# X‑Tablet — пользовательская версия

X‑Tablet — локальный companion-интерфейс для X‑Plane 12: приборы, live DataRefs, карта/позиция, системы, команды и подключение телефона/планшета по Wi‑Fi.

## Пользовательский сценарий

1. Запустить X‑Plane 12.
2. Запустить `X-Tablet.exe`.
3. На ПК нажать «Подключить телефон».
4. Отсканировать QR камерой телефона.
5. На телефоне подтвердить «Подключиться».

Python, Node.js и консоль для пользователя не нужны.

## Логи и диагностика

X‑Tablet пишет локальный журнал в:

`%LOCALAPPDATA%\\X-Tablet\\logs\\x-tablet.log`

Размер активного файла ограничен 5 МБ. Хранится до 5 архивов.

В интерфейсе есть раздел «Диагностика»: там отображаются версия X‑Plane, версия API, возраст последнего DataRef update, локальный IP и последние записи журнала.

Токены pairing не записываются в журнал.

## X‑Plane Web API

X‑Plane 12.1.1+ предоставляет локальный REST/WebSocket API. API v2 добавляет Commands, API v3 — дополнительные операции управления полётом. X‑Tablet выбирает максимальную поддерживаемую версию автоматически и использует REST для запросов/одноразовых Command activate и WebSocket для потоковых DataRef updates.

Для настоящих press/hold/release-команд следующий уровень интеграции — WebSocket `command_set_is_active`; REST activate используется для fire-and-forget команд, как рекомендовано официальной документацией X‑Plane.
