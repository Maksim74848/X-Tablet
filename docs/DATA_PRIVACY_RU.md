# X-Tablet — обработка данных

## Какие данные хранятся

Магазин получает от Telegram минимум данных, необходимых для покупки и обслуживания лицензии:

- Telegram ID покупателя;
- публичный username, если он установлен;
- имя/фамилия из профиля Telegram, если они переданы боту;
- сведения о покупке: тариф, сумма в Stars, дата, Telegram payment charge ID;
- сведения о лицензии: ключ, срок действия, тариф;
- технический Device ID и хэш локального device secret для привязки лицензии к одному ПК;
- обращения в поддержку.

Номер телефона, email, реквизиты банковской карты и пароль Telegram бот не получает.

## Для чего используются данные

Данные нужны для:

1. обработки покупки;
2. выдачи и продления лицензии;
3. выдачи доступа к установщикам;
4. привязки лицензии к устройству;
5. предотвращения повторной активации;
6. поддержки пользователей;
7. обработки платёжных вопросов и возможных возвратов.

## Что доступно администратору

Администратор может видеть в защищённой панели Telegram ID, username/имя, покупки, лицензии, статус устройства и обращения поддержки.

## Удаление

Перед коммерческим запуском владелец сервиса должен определить фактический срок хранения и порядок удаления данных с учётом применимого законодательства и необходимости хранить платёжные записи для поддержки/возвратов.
