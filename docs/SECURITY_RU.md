# Безопасность и лицензирование

## Ключ

После успешного Stars-платежа сервер создаёт случайный ключ вида:

`XT-XXXXX-XXXXX-XXXXX-XXXXX`

Ключ не содержит Telegram ID и не является предсказуемым.

## Привязка к ПК

При первом запуске desktop создаёт:

- `device_id` — идентификатор устройства;
- `device_secret` — случайный локальный секрет.

В сервере хранится только SHA-256 `device_secret`.

Активация:

`license key + device_id + device_secret` → сервер → bind.

Повторная активация другим device_id отклоняется.

Heartbeat повторно проверяет подписанный сервером activation token и device secret.

## Ограничения

Это защита от обычного копирования лицензии, а не DRM против мотивированного reverse engineering. Полностью защитить клиентское приложение от модификации невозможно, поскольку клиент запускается на компьютере пользователя.

## Скачать

Ссылка на файл короткоживущая и создаётся только после действующей подписки. Сервер выдаёт локальные release assets, не публикуя постоянную ссылку на ZIP.
