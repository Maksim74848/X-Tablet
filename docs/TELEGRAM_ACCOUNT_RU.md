# Вход через Telegram в X-Tablet

1. В X-Tablet открыть «Аккаунт» → «Войти через Telegram».
2. Приложение получает одноразовый код и открывает `https://t.me/<bot>?start=link_<code>`.
3. Пользователь нажимает Start в боте.
4. Бот связывает Telegram ID с одноразовым кодом.
5. X-Tablet получает профиль: имя, фамилия, username, тариф и дату окончания.
6. Если на Telegram-аккаунте есть активная лицензия и этот ПК ещё не привязан, X-Tablet может сразу выполнить claim устройства.

Код действует 10 минут и удаляется после claim. Программа не получает и не хранит Telegram Bot Token.
