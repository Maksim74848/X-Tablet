# X-Tablet — админ-панель

Админ-панель находится на license server:

`https://YOUR_LICENSE_SERVER/admin.html`

## Доступ

В `server/config.json` задайте длинный случайный `adminToken` (минимум 24 символа).

Панель использует его как `Authorization: Bearer ...`.

Токен не хранится в HTML сайта и не записывается в GitHub.

## Что показывает

- количество пользователей;
- активные Standard/Pro лицензии;
- общий объём полученных Stars в локальном журнале магазина;
- последние покупки;
- Telegram ID;
- публичный username/имя;
- ключ лицензии;
- дату окончания;
- привязанный Device ID;
- обращения поддержки.

## Персональные данные

Панель специально находится на license server, а не в публичном GitHub Pages `index.html`. Публичный сайт никогда не получает список пользователей или платежей.

Кнопка удаления данных удаляет пользовательский профиль, лицензии, платежные записи, session/download tokens и обращения поддержки из локального хранилища магазина. Перед боевым использованием определите вашу политику хранения с учётом платёжных/возвратных обязательств.
